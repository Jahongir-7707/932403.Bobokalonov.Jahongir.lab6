## Цель

Научиться запускать приложение на Node.js, использовать Express для создания HTTP-сервера, обрабатывать маршруты и параметры запроса, отдавать статические файлы и реализовывать PWA с офлайн-режимом.

## Что умеет приложение

- Показывает фиктивные курсы USD, EUR и CNY к рублю за 7 дней.
- Переключает валюты без перезагрузки страницы, запрашивая данные через API.
- Строит столбчатый график и показывает средний курс, первое и последнее значения, изменение за неделю.
- Открывает отдельную страницу «О проекте».
- Показывает состояние подключения к сети.
- Может устанавливаться как PWA и отображать сохранённые данные в офлайн-режиме.

## Маршруты Express

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/` | Главная страница с графиком |
| GET | `/about` | Страница о проекте |
| GET | `/api/status` | JSON со статусом сервера |
| GET | `/api/rates/:currency` | Курсы выбранной валюты за 7 дней |

В `server.js` для маршрутов используется `app.get()`, для JSON-ответов — `res.json()`, для отдачи HTML — `res.sendFile()`. Статические CSS, JavaScript, изображения и файлы PWA доступны через `express.static()`.

## Данные и обработка параметров

| Валюта | Массив курсов за 7 дней | Средний курс |
| --- | --- | --- |
| USD | `[90, 91, 92, 93, 94, 95, 96]` | 93 |
| EUR | `[98, 99, 97, 100, 101, 102, 99]` | 99,43 |
| CNY | `[12.3, 12.4, 12.5, 12.6, 12.5, 12.7, 12.8]` | 12,54 |

Значение `:currency` извлекается из `req.params.currency`, затем приводится к верхнему регистру. Среднее значение вычисляется как сумма семи курсов, делённая на 7, с округлением до двух знаков после запятой.

Пример запроса `GET /api/rates/USD`:

```json
{
  "currency": "USD",
  "rates": [90, 91, 92, 93, 94, 95, 96],
  "avg": 93
}
```

Query-параметры по условию варианта игнорируются: `/api/rates/USD?test=123` возвращает те же данные, что и `/api/rates/USD`.

## Обработка ошибок

- Если валюта не поддерживается, например `/api/rates/GBP`, сервер возвращает HTTP 404 и JSON с текстом ошибки и списком доступных валют.
- Для неизвестного маршрута сервер возвращает HTTP 404 с сообщением `Маршрут не найден`.
- При ошибке получения курсов интерфейс показывает сообщение вместо необработанного сбоя.
- При первой загрузке без сети данные могут быть недоступны: офлайн-режим работает после предварительного кеширования.

## PWA и офлайн-режим

- `manifest.json` содержит название приложения, параметры отображения, цвета и пути к иконкам 192×192 и 512×512.
- `app.js` регистрирует Service Worker через `navigator.serviceWorker.register('/sw.js')`.
- `sw.js` кеширует страницы, стили, скрипты, иконки и ответы API с курсами валют.
- После первой онлайн-загрузки приложение может открываться и переключать валюты без доступа к сети.
- Для работы Service Worker используется `localhost` или HTTPS.

## Проверка работы

1. В папке проекта выполнить `npm install`, затем `npm start`.
2. Открыть `http://localhost:3000`, переключить USD, EUR и CNY — график и показатели обновляются.
3. Перейти на `/about` — открывается страница о проекте.
4. Открыть `/api/status` и `/api/rates/USD` — сервер возвращает JSON.
5. Проверить `/api/rates/GBP` — ответ HTTP 404; проверить `/api/rates/USD?test=123` — query не влияет на результат.
6. В Chrome DevTools → Application → Service Workers проверить регистрацию Service Worker, затем в Network выбрать Offline и обновить страницу — сохранённые данные доступны из кеша.
7. В DevTools → Application → Manifest проверить наличие манифеста и иконок приложения.
