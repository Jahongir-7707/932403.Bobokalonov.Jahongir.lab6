О проекте

Учебное приложение для просмотра фиктивных курсов USD, EUR и CNY за 7 дней.

НАЗНАЧЕНИЕ

Лабораторная работа №6

Освоение Node.js, Express, маршрутизации, параметров URL, статических файлов и базовых возможностей прогрессивного веб-приложения (PWA).

ТЕХНОЛОГИИ

Стек проекта

Node.js · Express · HTML · CSS · JavaScript · Web App Manifest · Service Worker.

МАРШРУТЫ

API и страницы

GET / — главная
GET /about — о проекте
GET /api/status — состояние сервера
GET /api/rates/:currency — курсы валют

ОФЛАЙН-РЕЖИМ

Установка PWA

Service worker кеширует страницы, стили, скрипты и ответы API. После первого успешного посещения приложение можно открывать без сети.
